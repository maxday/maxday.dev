Short-Lived, Long Traced: Observability Deep Dive in Serverless

Abstract:

(will take place on September 23rd)

Serverless computing empowers rapid development and elastic scaling but brings a unique set of observability challenges. How do you trace ephemeral executions, handle cold starts, or monitor performance under strict memory and CPU constraints?

In this talk, we’ll explore how OpenTelemetry helps tackle observability in serverless environments. We’ll start with a quick refresher on the core concepts, then dive into advanced topics like sampling strategies, context propagation, and latency tracing, even for short-lived or event-driven functions that vanish in milliseconds.

Expect real-world insights, hard-learned lessons, and a sneak peek at a live demo that shows OpenTelemetry in action in a modern serverless stack.
